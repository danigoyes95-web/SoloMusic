# Juan José — Press Kit

`index.html` es un archivo único y autocontenido (HTML, CSS, JS e imágenes embebidas). No necesita build ni servidor.

## Publicar en GitHub Pages

1. GitHub → botón **+** arriba derecha → **New repository**.
2. Nombre: `juanjose-presskit`. Público. Sin README.
3. En el repo vacío: **uploading an existing file** → arrastra `index.html` y `README.md` → **Commit changes**.
4. **Settings → Pages** → Source: `Deploy from a branch`, branch `main`, folder `/ (root)` → **Save**.
5. En 1-2 minutos queda en `https://<tu-usuario>.github.io/juanjose-presskit/`.

Para actualizarlo después: **Add file → Upload files** en la raíz del repo, arrastra el `index.html` nuevo (mismo nombre = lo reemplaza), commit, y recarga con Cmd+Shift+R.
